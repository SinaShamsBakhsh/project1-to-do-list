# To-do list
## About This Repository 
This is a simple to-do list nothing more nothing less
## features
- add task to your to-do list 
- remove task from your to-do list
- list your tasks for you to see
- save your tasks in text file
## prerequisite
- python-dotenv
you can download python-dotenv by copying the code below and pasting it in the terminal
`pip install python-dotenv`
